At Evento I was the lead backend engineer responsible for maintaining the platform's APIs using NestJS, resolve bottlenecks from legacy code and be there for the frontend team inquiries.

I was responsible for migrating our pub-sub system from google's pub-sub, which was very tedious and hard to debug, to a more efficient and scalable system using RabbitMQ and NestJS's microservices architecture. This allowed us to handle a larger number of events and improve the overall performance of the platform.

I solved critical production problems before releasing which would otherwise had been catastrophic to the business, one example is that there was a cron job running a query so heavy that it lagged the entire platform.

Sometimes, due to the nature of the small teams of startups, I had to manage DevOps side tasks like managing services in ArgoCD, inspecting logs in Kubernetes and managing configurations in GCP.
