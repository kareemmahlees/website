TableX is a native, cross-platform, light-weight desktop database browser that supports PostgreSQL, MySQL and Sqlite. It was designed to be efficient and to meet the needs of developers bc it was created by a developer.

Striving towards performance, TableX has been optimized to handle large datasets and complex queries by incorporating some well known technologies such as virtualization, prefetching and caching. It also uses a modern web stack to ensure that the application runs smoothly on all platforms.

Inspired by VSCode, TableX also supports configurable settings to customize various parts of the application, such as the appearance, behavior and keyboard shortcuts that instantly takes effect.

A powerful query editor powered by codemirror is also available to enable complex query composition, with a built in vim mode and a rich set of features such as autocompletion, syntax highlighting, code folding and backend parsing to detect which tables are affected by the query and live update the UI. It also supports exporting to multiple different formats such as JSON and CSV.

To be an all-in-one tool, TableX also bundles [MetaX](https://github.com/kareemmahlees/metax) which is a powerful database management tool that allows you to create, edit, and manage your databases from a single interface.
