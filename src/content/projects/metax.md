MetaX wraps any database you provide it (PostgreSQL, MySQL and Sqlite) and exposes a documented REST and GraphQL interfaces through which you can create, drop and alter tables, execute queries and more.

It strives to be reliable via 90%+ test coverage, a lean bundle size (~10 MB zipped) and a very well documented APIs.
